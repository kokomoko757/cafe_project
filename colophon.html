Техническая реализация проекта (Colophon)

Этот сайт разработан в рамках университетского курса по предмету «Введение в веб-технологии». В качестве темы выбрана реально существующая сеть кофеен Global Coffee в городе Астана с флагманской точкой по адресу улица Туркестан, 4Б.

Семантика и архитектура разметки

При верстке страниц соблюдаются стандарты HTML5 и методология адаптивной компоновки Bootstrap 5.3.3. Пример фрагмента навигации: 

<nav class="navbar navbar-expand-lg">
  <ul class="navbar-nav">
    <li class="nav-item">
      <a class="nav-link" href="index.html">Главная</a>
    </li>
  </ul>
</nav>

Для быстрого сохранения кода в процессе разработки использовалась комбинация клавиш Ctrl + S.

Валидация и оформление текста

Все страницы проверены через официальный валидатор консорциума W3C:

Document checking completed. No errors or warnings to show.

В тексте также применяются полужирное начертание (тег b) и курсив (тег i) для стилистического выделения, где не требуется семантического веса (strong / em).

Мы стремились сделать сайт идеальным, адаптивным и полностью соответствующим спецификациям технического задания.
