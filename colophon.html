Технический паспорт проекта (Colophon)

Информация об архитектуре, технологиях, шрифтах и стандартах, использованных при создании сайта Global Coffee.

Технологический стек проекта

Клиентские библиотеки и разметка

  • HTML5 Semantic: Валидная семантическая структура тегов (header, nav, main, section, article, footer).
  • Bootstrap 5.3.3: Адаптивная 12-колоночная сетка, классы утилит и компоненты модалей и навигации.
  • jQuery 3.7.1: Официальная стабильная версия, подключенная через CDN перед пользовательскими скриптами.
  • CSS Freeze: Строго соблюдено ограничение на объем кастомного CSS (< 100 строк в css/base.css).

Типографика и дизайн-система

  • Playfair Display: Элегантный акцидентный шрифт с засечками для заголовков (H1–H3) и логотипа.
  • Inter: Высокочитаемый гротеск для основного текста, интерфейсных кнопок и таблиц.
  • Палитра кофейни: Теплый эспрессо (#3c2f2f), латте (#f9f7f4), золото (#ffc107) и глубокий синий акцент.
  • Доступность (a11y): Контрастность текста по WCAG 2.1 AA, поддержка навигации с клавиатуры и семантические метки.
