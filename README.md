# Global Coffee — локальная версия для endterm

Многостраничный учебный сайт кафе. Откройте START_LOCAL.cmd и перейдите по адресу http://127.0.0.1:8000. На этом компьютере установлен Python, который используется только для локального сервера. Остановка сервера — Ctrl+C в его окне.

Для загрузки Bootstrap, jQuery и шрифтов нужен интернет. Реальные заказы, платежи и бронь не отправляются в кофейню.

## Что изменено

- Меню: обычный JavaScript в js/menu.js, данные 19 позиций в js/menu-data.js. Позиции удалены из HTML и создаются циклом. Сохранены прежние фото, цены и классы оформления.
- Поиск по названию и описанию сочетается с категорией; результат показывает количество позиций. При пустой выдаче есть сообщение и кнопка сброса. Escape очищает фильтры. Кнопки обрабатываются через родителя, в том числе добавленные программой.
- Бронирование: jQuery в js/booking.js. Ошибки возле полей, строгий формат мобильного номера Казахстана, целое количество гостей, проверка вместимости стола и времени в будущем с часовым поясом Астаны.
- Заказ: jQuery в js/order.js. Расчёт суммы, доставка или самовывоз, ошибки возле полей, итоговый чек. После оформления корзина очищается. Сброс возвращает нужный блок доставки.
- Отзывы: jQuery в js/reviews.js. Исправлен порядок инициализации контейнера, проверяются поля, новый отзыв появляется сразу и сохраняется после перезагрузки. Повторное нажатие убирает лайк.
- Партнёрская форма: ошибки возле полей и точное сообщение о локальном результате вместо обещания записи в несуществующую базу.

## Файлы проекта

Рабочая версия — HTML в корне, папки js, css и images. main.js обслуживает общую навигацию и другие отдельные элементы; каталог меню не использует jQuery. public/js содержит копии скриптов для прежней настройки Vite; при правках их нужно обновлять вместе с js. src сохранена из исходного репозитория и не подключена к статическим страницам.

## Проверка перед защитой

Автоматически проверены загрузка скриптов всех десяти страниц в DOM-среде, локальные ссылки, файлы, якоря, поиск и категории меню, сброс, ошибки бронирования, подтверждение, сумма заказа, очистка корзины, добавление и восстановление отзывов, лайки. Реальный браузер, адаптивность и W3C-валидатор требуют отдельной проверки. npm build в этой локальной версии не проверялся.

В полученном репозитории не найден midterm tag, поэтому соответствие запрету на изменения после midterm не подтверждено. CSS не изменялся. В HTML меню убраны статические позиции и подключён файл данных.
