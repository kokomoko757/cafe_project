# Global Coffee Астана — Финальный проект (Endterm Submission)

Официальный многостраничный веб-проект сети кофеен **Global Coffee в Астане** (ул. Туркестан, 4Б).  
Разработан в строгом соответствии с требованиями курса *«Introduction to Web Technologies (Weeks 6–10: JavaScript & jQuery)»*.

Проект демонстрирует профессиональное разделение архитектуры на два независимых слоя:
1. **Plain JavaScript (Недели 6–8)** — полноценные интерактивные модули на нативном стандарте DOM без сторонних библиотек.
2. **jQuery 3.7.1 (Недели 9–10)** — продвинутые интерактивные модули с селекторами, обходом DOM (traversal), цепочками методов (chaining), эффектами (effects) и делегированием событий.

## 2. Разделение модулей: Plain JavaScript vs jQuery (Строго разделены)

Требование рубрики: *«Keep the two apart: a feature is either plain JavaScript or jQuery, never both, and keep them in separate files.»*

### Часть 1: Модули на Plain JavaScript (Недели 6–8)
Реализовано в файле **`js/booking.js`** (страницы `booking.html` и `details.html`):
1. **Данные в массивах и объектах в начале файла:** массив `TABLES_CATALOG` содержит каталог столов с вместимостью, зонами и тарифами депозита.
2. **Динамическая генерация разметки из кода:** баннер выбранного столика (`#selectedTableBanner`) и блок подтверждения бронирования с кодом `#BK-2026-XXXX` генерируются исключительно в коде через `document.createElement()` и вставляются в DOM (в исходном HTML их нет).
3. **Функции с параметрами и возвращаемым значением:**
   - `findTableById(tableId)` — поиск стола в каталоге, вызывается при клике и при восстановлении брони.
   - `calculateBookingDeposit(guestCount, ratePerGuest)` — возвращает `guests * rate`.
   - `generateBookingReference(prefix)` — генерирует уникальный код вида `#BK-2026-XXXX`.
   - `formatPriceKzt(amount)` — форматирует сумму в тенге с пробелами.
4. **Условия и логика:**
   - Проверка вместимости столика (`guestCount > selectedTable.seats`) с запретом превышения.
   - Проверка даты бронирования (`selectedDate < today`) с запретом брони в прошлом.
5. **Вычисляемые значения:** расчетный депозит (`guestCount * 1000 ₸`) рассчитывается программно в реальном времени.
6. **События и делегирование:**
   - Обработчики привязаны в коде (0 атрибутов `onclick`).
   - Использовано 4 типа событий: `click`, `input`, `change`, `submit`.
   - Делегированный обработчик `tableContainer.addEventListener('click', ...)` перехватывает клики по кнопкам столов через `event.target.closest()`.
7. **Валидация формы:**
   - `event.preventDefault()` предотвращает перезагрузку страницы.
   - Проверка каждого поля: имя, телефон (+7 7XX XXX-XX-XX), email, дата, время, гости.
   - Инлайн-ошибки с классом `is-invalid error` выводятся рядом с ошибочным полем.
   - Ошибки очищаются на лету по событию `input` / `change`.

### Часть 2: Модули на jQuery 3.7.1 (Недели 9–10)
Реализовано в файлах **`js/order.js`**, **`js/menu.js`**, **`js/reviews.js`**, **`js/location.js`**, **`js/partner.js`**:
1. **Селекторы:** `#orderForm`, `input[name="order_items"]:checked`, `.qty-input`, `#filterAll`, `.table-secondary`.
2. **Обход DOM (Traversal):** `.closest('.card')`, `.find('.card-header')`, `.parent()`, `.siblings('button')`, `.each()`.
3. **Цепочки методов (Method Chaining, 3+ методов):**
   ```javascript
   // Пример из js/menu.js:
   $(this)
     .addClass('active btn-outline-primary')
     .removeClass('btn-outline-secondary')
     .siblings('button')
     .removeClass('active btn-outline-primary')
     .addClass('btn-outline-secondary');
   ```
4. **Эффекты jQuery с длительностью и колбэками:**
   - `.slideDown(300)` и `.slideUp(300)` с переключением видимости и `required`.
   - `.fadeIn(400)` и `.fadeOut()` для плавного появления динамических карточек.
   - `.animate({ scrollTop: offset }, 350)` для плавной прокрутки к результатам.
5. **Делегирование событий в jQuery:**
   ```javascript
   // Пример из js/reviews.js:
   $('#reviewsGrid').on('click', '.like-review-btn', function (event) { ... });
   ```
   Обработчик лайка привязан к существующему родителю `#reviewsGrid`, благодаря чему динамически добавляемые отзывы мгновенно реагируют на клики.

## 3. Сравнение 3 модулей для защиты (Clean JS vs jQuery)

Для демонстрации преподавателю на устной защите исходные реализации сохранены в файле **`old-js-version.js`**:

1. **Валидация формы заказа и инлайн-ошибки (`js/order.js`):**
   - *Plain JS:* 45 строк с ручным обходом `querySelectorAll`, `classList.add/remove`, `document.createElement('div')` и `appendChild`.
   - *jQuery:* Селекторы `$('#customer_name')`, `$.trim()`, обход `.parent().find(...)`, цепочки классов и анимации `.slideDown(200)` / `.slideUp(150)`.
2. **Показ и скрытие блоков доставки / самовывоза (`js/order.js`):**
   - *Plain JS:* Ручной поиск через `closest` и `nextElementSibling`, переключение класса `.hidden`.
   - *jQuery:* Плавный аккордеон `.slideDown(300)` / `.slideUp(300)` с синхронизацией `required` через `.prop()`.
3. **Динамическая карточка рекомендации из массива (`js/main.js`):**
   - *Plain JS:* 15 строк с разрозненными вызовами `createElement`, `textContent` и `appendChild`.
   - *jQuery:* Конструктор `$('<div>')` с шаблоном `.html(...)`, методом `.append()` и эффектом `.fadeIn(400)`.

## 5. Проверка качества сборки, линтинга и тестов

В проекте настроена автоматическая проверка качества:

```bash
# 1. Запуск модульных тестов чистой логики (Node.js test runner)
npm test

# 2. Проверка типов TypeScript и синтаксиса JavaScript
npm run lint

# 3. Продакшн-сборка всех 10 HTML-страниц и ассетов
npm run build
```

Все команды выполняются с кодом возврата `0` (без ошибок и предупреждений).
